# Dataset Factory: AGENT 2027 short experience paper

This directory contains the separate five-page version authorized by Eduardo.
The longer manuscript and analyses remain unchanged in `../paper/`.

Build with `sh paper-agent27-short/build.sh`. The PDF is `output/paper.pdf`.
The portable LaTeX archive is `output/paper-source.zip`.

`BRIEF.md` records scope; `analysis/RECORD-INPUTS.md` maps the source checks;
`analysis/release-records.json` supports the combined release table. Verification
and remaining work are recorded in `PROGRESS.md` and the final sign-off.

[SBIR semantic review experiment plan](SEMANTIC-REVIEW-EXPERIMENT-PLAN.md)
describes the completed 30-review intervention test. The submitted manuscript
is unchanged. [Results and recommendation](../experiments/sbir-semantic-review/FINDINGS.md)
are retained separately with the frozen inputs and all run records.
